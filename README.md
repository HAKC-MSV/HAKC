# HAKC

Instructions for how to build all code and run the ROS2 demo in QEMU.

## Prerequisites

* `Binutils 2.33.1+`
* `aarch64-linux-gnu`
* `bear`

## TL;DR

1. `bash scripts/support/init.sh`
2. `cd cmake-build-hakc`
3. `cmake --build . --target hakc-linux-x86-enforcement`

## Set up

1. `bash scripts/support/init.sh`

## Build LLVM

1. `bash scripts/support/setup-llvm.sh`
2. `cd cmake-build-hakc`
3. `cmake --build . --target clang`

## Performing kernel analysis

Creating the initial compartmentalization can be accomplished (assuming the python virtual
environment is still active) by

1. `cd cmake-build-hakc`
2. `cmake --build . --target hakc-linux-x86-analysis`

This target first builds a compilation database for the kernel, and then that database is
used to perform analysis and build the compartmentalization policy. The database storing
the compartmentalization policy will be in `cmake-build-hakc/linux/x86/hakc-db`. The
compartmentalization policy is generated by the server automatically once all compilation
is complete. Note, this also adjusts the compartmentalization for the ROS 2 demo by
default, but this can be controlled by editing the `hakc-server-config.yaml` and removing
the
`adjustment-path` entry.

## Build the protected Kernel

Note, these directions imply a valid HAKC configuration and policy server configuration is
created, and all paths are correct. See [docs/README.md](docs/README.md) for more
information.

1. `cd cmake-build-hakc`
2. `cmake --build . --target hakc-linux-x86-enforcement`

Running `cmake --build . --target hakc-linux-x86-enforcement` first will run the
`hakc-linux-x86-analysis` target first

## Run HAKC test suite standalone / LLVM + HAKC tests

1. `cd cmake-build-hakc`
2. `cmake --build . --target check-{hakc, llvm}`
