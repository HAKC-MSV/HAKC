# HAKC

Instructions for how to build all code and run the ROS2 demo in QEMU.

## Prerequisites

* `Binutils 2.33.1+`
* `aarch64-linux-gnu`
* `busybox`
* `qemu-system-x86_64`

## TL;DR

1. `source .envrc`
2. `cmake --preset debug`
3. `cmake --build $HAKC_BUILD_ROOT --target run-x86_64-rosdemo-hakc-kernel`

The built kernel will be installed at `cmake-build-hakc/linux/x86_64/rosdemo/hakc-kernel`.

## Set up

1. `git submodule update --init --recursive`
2. `source .envrc`

## Build LLVM

1. `cmake --preset debug`
2. `cmake --build $HAKC_BUILD_ROOT --target clang`

## Performing kernel analysis

Creating the initial compartmentalization can be accomplished (assuming the python virtual
environment is still active) by

1. `cmake --build $HAKC_BUILD_ROOT --target hakc-linux-x86_64-rosdemo-analysis`

This target first builds a compilation database for the kernel, and then that database is
used to perform analysis and build the compartmentalization policy. The database storing
the compartmentalization policy will be in
`cmake-build-hakc/linux/x86_64/rosdemo/hakc-db`. The compartmentalization policy is
generated by the server automatically once all compilation is complete. Note, this also
adjusts the compartmentalization for the ROS 2 demo by default, but this can be controlled
by editing the
`cmake-build-hakc/linux/x86_64/rosdemo/hakc-server-config.yaml` and removing the
`adjustment-path` entry.

## Build the protected Kernel

Note, these directions imply a valid HAKC configuration and policy server configuration is
created, and all paths are correct. See [docs/README.md](docs/README.md) for more
information.

1. `cmake --build $HAKC_BUILD_ROOT --target hakc-linux-x86_64-rosdemo-enforcement`

Running `cmake --build $HAKC_BUILD_ROOT --target hakc-linux-x86_64-rosdemo-enforcement`
first will run the `hakc-linux-x86_64-rosdemo-analysis` target first.

## Run HAKC test suite standalone / LLVM + HAKC tests

1. `cmake --build $HAKC_BUILD_ROOT --target check-{hakc, llvm}`

## Debugging Tips

Generating the enforcement kernel uses the server implemented at
[llvm-project/llvm/utils/hakc/hakc-server-process](llvm-project/llvm/utils/hakc/hakc-server-process).
By default, it compiles every file present in the compilation database provided by the
config provided as a command line argument (currently, by default
`cmake-build-hakc/llinux/x86_64/rosdemo/hakc-config.yaml`). However, you can invoke the
server and provide the config and a list of files to compile, and the server will only
compile the provided files. Additionally, the server takes in a required mode, which is
typically either
`analysis` or `enforcement`. However, you can add `-ir` to either mode, and the server
will generate a human readable LLVM IR output instead. This file will have the same name
and location as the expected object file, but will end in `.ll`. This file can be used to
examine the final transformation of any source file.

## KVM Kernel

The compartmentalized KVM kernel can be built the same way as the above kernel, but
replacing `rosdemo` with `kvm` in all of the above targets and paths.
